Job Maintenance Help

This page allows you to run scheduled system jobs on demand. The buttons on this page trigger the normal background processing tasks that the system usually runs in the background at set intervals. When you press a button, the job begins immediately and may take several minutes to complete.

When the job finishes, you will be returned to the home page. If a problem occurs during processing, an error message will be displayed at the top of the page.

Collect SWIMS Data since beginning of time

This option runs the process that imports historic SWIMS data into the system. Use this only when you need to load or refresh older SWIMS records that are not yet present in the database.

Truncate audit logs

This option removes the current audit log entries to keep the system log data to a manageable size. Use this only when you are intentionally clearing audit records.

Process FTP files

This option runs the data import process for files received through FTP. It is used to ingest uploaded data files that have been transferred to the system and are awaiting processing.
