Funding Source Maintenance Help

You have the ability to add, update, and delete funding sources on this page. Funding sources are used to identify the project, grant, or program associated with a measurement or set of measurements. You can click on a column heading to sort the list by that field. Clicking once sorts ascending; clicking again sorts descending.

If something goes wrong, a message will appear at the top of the page. Correct the issue and try again. If you continue to have issues, copy the error message or take a screenshot and contact the administrator.

Inserting

To add a new funding source, press the + icon in the upper-right corner of the grid header. A blank row will appear below the header. Fill in the required values and click the + icon at the end of the row to save it. If you decide not to add the entry, click the same + icon in the header to cancel the blank row.

Deleting

Any funding source can be PERMANENTLY removed by clicking the trashcan icon at the end of the row. This is a permanent action and should only be used when the funding source is no longer valid or is no longer in use.

Updating

Any funding source can be updated by clicking the pencil icon at the end of the row. Make the necessary changes and then click the checkmark icon to save. If you change your mind, click the X icon to cancel the edits.

Attribute Descriptions
Name

The official name of the funding source. This is required and should clearly identify the grant, program, or project.

Description

A summary or explanation of the funding source. This field is required and helps clarify what the funding supports.

Start Date

The date the funding source became active. This field is required.

End Date

The date the funding source ended or is expected to end. This field is required.
