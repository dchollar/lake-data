Location Maintenance Help

You have the ability to add, update, and delete monitoring locations on this page. Locations are the specific places where data is collected within a site. You can click on a column heading to sort the list by that field. Clicking once sorts ascending; clicking again sorts descending.

If something goes wrong, a message will appear at the top of the page. Correct the issue and try again. If you continue to have issues, copy the error message or take a screenshot and contact the administrator.

Inserting

To add a new location, press the + icon in the upper-right corner of the grid header. A blank row will appear below the header. Enter the required information and then click the + icon at the end of the row to save it. If you change your mind, click the + icon again in the header to remove the blank row.

Deleting

Any location can be PERMANENTLY removed by clicking the trashcan icon at the end of the row. This action is permanent and should only be used when the location no longer exists or should no longer be used by the system.

Updating

Any location can be updated by clicking the pencil icon at the end of the row. When the row becomes editable, change the fields as needed. If you change your mind, click the X icon to cancel. When you are satisfied, click the checkmark icon to save the updates immediately.

Attribute Descriptions
Site

This is the general site that the monitoring location belongs to. It identifies the broader area associated with the location.

Description

This is the name or description of the monitoring location. This is the primary identifier used to distinguish one location from another and is required.

Comment

Use this field for notes or additional details about the location, such as how it is used or any relevant operational notes.

Latitude

The latitude of the location, if known. This value may be used for mapping or reporting purposes.

Longitude

The longitude of the location, if known. This value may be used for mapping or reporting purposes.
