Measurement Maintenance Help

You are able to review, update, and delete measurement records here. This page lists the individual data points that have already been entered into the system and can be filtered by site, location, characteristic, and other values. You can click on any column heading to sort the list by that field. Clicking the heading once sorts ascending; clicking it again sorts descending.

If something goes wrong, a message will appear at the top of the page. Correct the issue and try again. If you continue to have issues, copy the error message or take a screenshot and contact the administrator.

Adding Measurements

New measurements are not created from this page. Use the Enter Data tab to add new observations. This maintenance page is intended for correcting and managing measurement records that already exist in the system.

Deleting

Any measurement can be PERMANENTLY removed from the system by clicking the trashcan icon at the end of the row. This is a permanent action and the record will be removed immediately after confirmation. Use this only when a data point should no longer exist in the dataset.

Updating

Any measurement can be updated by clicking the pencil icon at the end of the row. When you click the pencil icon, the row becomes editable and you can change the values available for that record. If you decide not to keep the changes, click the X icon to cancel. When you are done, click the checkmark icon to save the changes. Once saved, the database record is updated immediately. If an error occurs, you will see a message at the top of the grid.

Filtering and Search

The grid includes filtering controls that allow you to narrow the list of records. Use the filter fields to limit the display by site, location, characteristic, funding source, or the person who created or modified the record. This is useful when you need to review a subset of measurements for quality control or editing.

Attribute Descriptions
Site

This identifies the general site associated with the measurement. It is assigned when the data was entered and is not editable from this page.

Location

This identifies the specific monitoring location associated with the measurement. It is assigned when the data was entered and is not editable from this page.

Characteristic

This identifies the type of measurement being recorded, such as stream flow, water level, or another monitored condition. It is assigned when the data was entered and is not editable from this page.

Funding

If the measurement was collected under a specific funding source or project, select that funding source here. This field can be updated if the record needs to be reassigned.

Collection Date

This is the date the measurement was collected. This is the most important date associated with the measurement and is required.

Depth

This is the depth in feet at which the specific measurement was taken, if applicable. Not all characteristics require a depth value.

Value

This is the actual measurement value recorded for the sample. The value must match the unit and method associated with the selected characteristic.

Comment

Any notes or remarks associated with the measurement can be entered here. This field is optional and should be used to document unusual conditions, observations, or clarifications.

Created By / Modified By

These fields show the user who created the measurement and the user who last modified it. They are informational and are maintained by the system.
