Characteristic Maintenance Help

You have the ability to add, update, and delete monitoring characteristics on this page. Characteristics are the types of measurements collected, such as temperature, flow, level, or other conditions. You can click on a column heading to sort the list by that field. Clicking once sorts ascending; clicking again sorts descending.

If something goes wrong, a message will appear at the top of the page. Correct the issue and try again. If you continue to have issues, copy the error message or take a screenshot and contact the administrator.

Inserting

To add a new characteristic, press the + icon in the upper-right corner of the grid header. A blank row will appear below the header. Enter the required values and click the + icon at the end of the row to save it. If you decide not to add the item, click the same + icon in the header again to remove the blank row.

Deleting

Any characteristic can be PERMANENTLY removed by clicking the trashcan icon at the end of the row. This action is permanent and should only be used when the characteristic is no longer valid or should no longer be used in data collection.

Updating

Any characteristic can be updated by clicking the pencil icon at the end of the row. Make the needed edits in the row and then click the checkmark icon to save the changes. Use the X icon if you want to cancel the edits.

Attribute Descriptions
Units

This is the unit of measure associated with the characteristic, such as feet, degrees Celsius, or cubic feet per second. This field is required.

Description

This is a clear description of the measurement type. This field is required and should describe what the measurement represents.

Symbol

This is a short symbol or abbreviation used to identify the characteristic. This field is required and should be concise.

Depth Profile

Check this box when the characteristic is measured at varying depths and requires a depth value for each reading. Leave it unchecked when no depth is needed.

Type

This identifies the category or type of characteristic. The list of available types is provided by the system and should be used to classify each measurement type.
